# ppt-conjecture-numerics
Testing the PPT conjecture, that the composition of two PPT channels T1 and T2 becomes entanglement-breaking, i.e. Choi matrix C_(T1 T2) is separable. This is done by testing if for positive maps Phi (id tensor Phi)(C_(T1 T2)) is still PSD. For a fixed positive map, finding the minmal eigenvalues of this expression for all PPT channels T1 and T2 is performed as a SDP. For the positive maps the Breuer Hall maps are chosen (since optimality and decomposability) and 'optimized' (without convergence) over its unitaries. 

The complete optimization over all positive maps is still an open problem and would solve the PPT conjecture in this way.
